# DAIOE has moved

**This repository is retired.** The DAIOE scores are now published as a
citable, versioned dataset on Zenodo, and that is the only canonical
download path:

- **Scores (all versions):** https://doi.org/10.5281/zenodo.21873967
- **This version (v1.0.0):** https://doi.org/10.5281/zenodo.21873968
- **Construction pipeline, documentation and quick starts:**
  https://github.com/Magnus-L/daioe-pipeline

The files previously hosted here predate the release and should no longer be
used: the release carries the verified frozen 2010–2023 index, the 2024
refresh, percentile companions and full documentation, and each vintage is
cell-identically protected and citable by DOI. Cite the version, the object
(which vintage) and the filename you loaded.

*Retired 6 September 2026. The old files remain in this repository's history
for provenance only.*
